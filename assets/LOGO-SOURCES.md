# Logo sources and publication notes

Prepared September 27, 2026 for the private README update. This is a source and rights check, not legal advice or a grant of permission. Do not treat third-party marks as licensed under this repository's MIT license. The README uses only the two files in `assets/`. The other named agents are text-only until their mark permissions are resolved.

- `assets/hermes-agent.png` - the Hermes Agent desktop icon, from the official NousResearch repository: https://github.com/NousResearch/hermes-agent/blob/main/apps/desktop/assets/icon.png (bytes: https://raw.githubusercontent.com/NousResearch/hermes-agent/main/apps/desktop/assets/icon.png). Its repository carries an MIT license, https://github.com/NousResearch/hermes-agent/blob/main/LICENSE. The bundled icon retains the upstream MIT notice below; MIT does not grant trademark rights or endorsement. This icon is used as a small identifier, not as the hub's logo.
- `assets/chatgpt.png` - OpenAI's GitHub organization avatar, not a separately published ChatGPT-specific mark: https://github.com/openai (bytes: https://avatars.githubusercontent.com/u/14957082?v=4). OpenAI's brand guidance, https://openai.com/brand/, says use its logo only when directly related to OpenAI services, exactly as provided, and acknowledge ownership. README usage identifies the ChatGPT route. Consider dropping this icon if you require a ChatGPT-specific official asset or an explicit permission review. Do not imply affiliation or endorsement.
- Muse - current Meta Muse official asset located at https://muse.ai/landing/brand/muse-logo.svg (seen on https://muse.ai/), **not included**. The older search result at `muse.ai/brand` refers to Skiv, a different former muse.ai product; it was not used. Meta's current Muse terms, https://muse.ai/terms, reserve Muse IP and grant access to the service, not redistribution of the mark. Seek permission or a specific brand-use policy before bundling this SVG.
- Instinct - official site favicon at https://instinct.com/redesign/favicon.ico (seen on https://instinct.com/), **not included**. The terms at https://instinct.com/terms restrict use or reproduction of a logo and reserve trademark rights. Seek explicit permission before bundling. The downloaded .ico endpoint serves PNG data; if permitted later, use a `.png` filename.
- Claude - official site favicon at https://assets.claude.com/95a868946ac8a31e5ff832e2899f294aa368b836.png?w=32&h=32 (linked on https://claude.com/), **not included**. Anthropic's trademark guidelines require its specific permission and advance approval of materials: https://www.anthropic.com/legal/trademark-guidelines. Claude is planned, not a verified route.
- Tencent WorkBuddy - official site icon at https://download.codebuddy.ai/web/workbuddy/ea2a61614c71b7bed74ab35460e918796a083362/assets/logo.svg (linked from https://www.workbuddy.ai/), **not included**. WorkBuddy's service agreement section 9.3 expressly bars use/display of Tencent logos without prior written consent: https://www.workbuddy.ai/document/term. Name the planned connection in text only unless consent is obtained.

If another logo is later cleared, keep its supplied proportions, link it as `assets/<agent-name>.<extension>`, and use an empty image alt next to the agent name (the text already supplies the accessible name). Recheck the provider's then-current brand rules and make the pending/verified distinction clear.
